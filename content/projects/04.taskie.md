# Taskie - менеджер задач

Платформа для управления задачами и проектами. В роли руководителя группы разработки отвечал за архитектурные решения, качество кода и организацию командной работы.

## О проекте

Современный task-менеджер для командной работы с акцентом на производительность и масштабируемость. Проект разрабатывался командой frontend-разработчиков под моим техническим руководством.

## Роль технического лидера

### Архитектурное руководство

**Внедрение Feature-Sliced Design**
- Разработка архитектуры приложения с использованием FSD методологии
- Разделение на слои: app, pages, widgets, features, entities, shared
- Создание гайдлайнов по структуре файлов и именованию
- Настройка import-правил и линтеров для контроля архитектуры

**Технические стандарты**
- Разработка coding standards для команды
- Настройка ESLint и Prettier конфигураций
- Определение best practices для Vue.js и TypeScript
- Создание библиотеки переиспользуемых компонентов

### Управление качеством кода

**Код-ревью**
- Проверка всех Pull Request перед слиянием
- Контроль соблюдения архитектурных принципов
- Проверка производительности и оптимизации
- Обучение команды через комментарии в PR

**Процессы разработки**
- Настройка Git Flow и branching strategy
- Организация процесса релизов
- Контроль технического долга
- Рефакторинг проблемных участков кода

### Работа с командой

**Консультирование**
- Помощь разработчикам в решении сложных задач
- Консультации по Vue.js, TypeScript, Pinia
- Разбор архитектурных решений
- Проведение технических обсуждений

**Повышение компетенций**
- Обучение команды современным практикам
- Демонстрация лучших подходов на примерах
- Code review как инструмент обучения
- Создание внутренней документации

# Я хочу помочь - благотворительная платформа

Благотворительная платформа для организации волонтёрской помощи нуждающимся. В роли руководителя группы разработки отвечал за архитектуру проекта, организацию процессов и техническое качество.

## О проекте

Социальная платформа, объединяющая людей, готовых помочь, с теми, кто нуждается в поддержке. Система включает регистрацию мероприятий, управление волонтёрами и координацию благотворительных акций.

## Техническое руководство

### Архитектура проекта

**Внедрение Feature-Sliced Design**
- Проектирование архитектуры Vue приложения с нуля
- Разделение на изолированные слои для масштабируемости
- Создание соглашений по структуре и именованию файлов
- Настройка автоматических проверок архитектуры

**Организация кодовой базы**
- Разделение бизнес-логики и UI-компонентов
- Создание переиспользуемых entities и features
- Настройка shared слоя с утилитами и UI-kit
- Оптимизация зависимостей между модулями

### Участие в разработке

**Сложные UI-компоненты**
- Многошаговые формы с валидацией (Vee-Validate + Yup)
- Компоненты для работы с ролевой моделью
- Динамические элементы с реактивным состоянием
- Интерактивные таблицы и списки

**Интеграция с backend**
- Настройка работы с REST API
- Управление состоянием через Pinia
- Обработка ошибок и retry-логика
- Оптимизация запросов и кэширование

### Управление командой

**Организация процессов**
- Постановка и декомпозиция технических задач
- Планирование спринтов и контроль сроков
- Проведение daily stand-up и технических обсуждений
- Организация retrospective для улучшения процессов

**Контроль качества**
- Код-ревью всех Pull Request
- Проверка соответствия архитектурным стандартам
- Выявление и устранение технического долга
- Рефакторинг критических участков кода

**Поддержка команды**
- Консультации по архитектурным решениям
- Помощь в работе с API и state management
- Обучение best practices Vue.js и TypeScript
- Менторинг junior-разработчиков

## Сложные задачи

### Ролевая система
- Разработка гибкой системы разграничения доступа
- Проверка прав на уровне компонентов и роутов
- Динамическое отображение UI в зависимости от ролей
- Управление разрешениями через Pinia store

### Работа с формами
- Сложная валидация с зависимыми полями
- Условная логика отображения полей
- Автосохранение черновиков
- Обработка ошибок с серверной валидацией

### Оптимизация производительности
- Виртуализация больших списков
- Lazy loading компонентов и роутов
- Оптимизация реактивности
- Мемоизация вычислений

- Повысил стабильность приложения через систематическое ревью

- Создал техническую документацию и гайдлайны для команды

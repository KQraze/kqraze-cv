# Lytko - система управления умным домом

Progressive Web Application для управления системой умного дома с реальным подключением к IoT-устройствам на базе микроконтроллеров ESP через протоколы MQTT и WebSocket.

## О проекте

Инновационная платформа для управления умным домом от российской компании Lytko. Проект включает веб-интерфейс для контроля освещения, климата и других систем через микроконтроллеры ESP.

## Технические вызовы IoT

### Работа с микроконтроллерами
- Интеграция с ESP32/ESP8266 контроллерами
- Обмен данными через MQTT брокер
- WebSocket соединения для реал-тайм коммуникации
- Обработка различных состояний устройств

### Протоколы реального времени

**MQTT (Message Queuing Telemetry Transport)**
- Подписка на топики устройств
- Публикация команд управления
- Quality of Service (QoS) для надёжности
- Обработка offline/online статусов

**WebSocket**
- Двунаправленная связь с устройствами
- Минимальная задержка команд
- Автоматическое переподключение
- Heartbeat для контроля соединения

## Разработанные решения

### PWA (Progressive Web App)

**Офлайн-функциональность**
- Service Worker для кэширования
- Работа без интернета с локальными данными
- Синхронизация при восстановлении связи
- Background sync для команд

**Установка на устройства**
- Добавление на главный экран смартфона
- Полноэкранный режим как нативное приложение
- Push-уведомления о событиях
- Оптимизация для мобильных устройств

### Lytko 101 - Термостат

**Разработка с нуля**
- Веб-интерфейс для управления термостатом
- Отображение текущей температуры в реальном времени
- Переключение режимов работы (нагрев/охлаждение/авто)
- Настройка расписания температур
- Графики изменения температуры

**Взаимодействие с backend**
- REST API для получения настроек
- WebSocket для обновлений в реальном времени
- Отправка команд на контроллер
- Обработка ошибок связи

## Рефакторинг проекта

### Переход на Feature-Sliced Design

**Проблемы legacy кода**
- Отсутствие чёткой структуры
- Смешанная бизнес-логика и UI
- Сложность добавления новых устройств
- Дублирование кода

**Решение через FSD**
- Реорганизация в слоистую архитектуру
- Изоляция логики устройств в entities
- Переиспользуемые features для управления
- Чистые границы между модулями

### Оптимизация

**Производительность**
- Минимизация перерисовок при обновлениях
- Дебаунсинг команд управления
- Оптимизация работы с WebSocket
- Ленивая загрузка модулей устройств

**Адаптация под устройства**
- Тестирование на реальных контроллерах
- Учёт задержек и таймаутов
- Обработка нестабильного соединения
- Fallback стратегии

# Lytko - система управления умным домом

PWA-приложение для управления системой умного дома с подключением к микроконтроллерам ESP через MQTT и WebSocket.

## Технические вызовы

Работа с IoT-устройствами требовала глубокого понимания протоколов обмена данными в реальном времени и оптимизации производительности.

## Основные достижения

- Разработка PWA для офлайн-работы и установки на устройства
- Интеграция с микроконтроллерами ESP через MQTT и WebSocket
- Рефакторинг legacy кода с переходом на Feature-Sliced Design
- Разработка интерфейса для термостата Lytko 101 с нуля
- Оптимизация под реальные устройства

## Технологии реального времени

Использование современных протоколов для мгновенного обмена данными между устройствами умного дома и веб-интерфейсом.

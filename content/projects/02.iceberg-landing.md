# Айсберг - корпоративный лендинг

Современный корпоративный лендинг для компании Айсберг, разработанный на Nuxt 3 с полной поддержкой серверного рендеринга и оптимизацией для поисковых систем.

## О проекте

Разработка высокопроизводительного корпоративного сайта с акцентом на SEO-оптимизацию и пользовательский опыт. Проект реализован с использованием современных подходов к архитектуре и технологий Vue/Nuxt экосистемы.

## Особенности реализации

### Серверный рендеринг (SSR)
- Полная поддержка SSR для быстрой загрузки и индексации поисковиками
- Оптимизация метатегов и структурированных данных для SEO
- Гидратация на клиенте без потери интерактивности
- Статическая генерация для максимальной производительности

### Архитектура

**Nuxt BFF (Backend for Frontend)**
- Оптимизация API-запросов на стороне сервера
- Агрегация данных для минимизации запросов от клиента
- Защита чувствительных данных и токенов

**Feature-Sliced Design (FSD)**
- Модульная структура проекта для лучшей масштабируемости
- Разделение по слоям: app, pages, widgets, features, entities, shared
- Изолированные компоненты с чёткими границами ответственности
- Упрощение командной разработки и поддержки кода

## Реализованный функционал

### Дизайн и UX
- Полностью адаптивный дизайн для всех типов устройств
- Кроссбраузерная совместимость (Chrome, Firefox, Safari, Edge)
- Плавные анимации и переходы для улучшения восприятия
- Интерактивные элементы с обратной связью

### Интеграция и данные
- Интеграция с REST API для динамического контента
- Реактивное отображение данных с автоматическими обновлениями
- Оптимизация загрузки изображений и ресурсов
- Ленивая загрузка компонентов для быстрой инициализации

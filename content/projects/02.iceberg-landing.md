# Айсберг - корпоративный лендинг

Современный корпоративный лендинг с полной поддержкой серверного рендеринга и оптимизацией для SEO.

## Особенности проекта

- Разработка с нуля на Nuxt 3 с использованием современного стека
- Полная поддержка SSR для оптимальной SEO-оптимизации
- Чистая архитектура с использованием BFF и Feature-Sliced Design
- Адаптивный дизайн с поддержкой всех устройств и браузеров
- Интерактивные элементы и анимации для улучшения пользовательского опыта

## Архитектура

Проект построен с использованием современных подходов к архитектуре фронтенд-приложений, включая Feature-Sliced Design для лучшей масштабируемости и BFF паттерн для оптимизации взаимодействия с бэкендом.

# Портал дополнительного профессионального образования

Разработка регионального портала для системы дополнительного профессионального образования с полным функционалом управления пользователями, программами обучения и генерацией документов по госстандартам.

## Основные возможности

- Пошаговый интерфейс с валидацией форм
- Ролевая система доступа с защищёнными маршрутами
- Административная панель для управления всеми аспектами системы
- Генерация PDF-документов с кастомными шрифтами по госстандартам
- Адаптивный интерфейс с таблицами, модальными окнами и фильтрами

## Технический стек

Проект построен на современном React-стеке с упором на типобезопасность и производительность.

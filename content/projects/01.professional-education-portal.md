# Портал дополнительного профессионального образования

Региональный портал для системы дополнительного профессионального образования, разработанный на React с полным функционалом управления учебным процессом, пользователями и генерацией официальных документов.

## О проекте

Это современное веб-приложение для автоматизации процессов дополнительного профессионального образования в регионе. Портал объединяет образовательные учреждения, слушателей и администраторов, предоставляя удобные инструменты для управления программами обучения, контроля качества и генерации отчётной документации.

## Основные возможности

### Пошаговый интерфейс
- Многошаговые формы с валидацией на каждом этапе (React Hook Form + Yup)
- Сохранение прогресса и возможность вернуться к предыдущим шагам
- Автоматическая валидация данных в реальном времени

### Ролевая система
- Реализация защищённых маршрутов с помощью React Router DOM
- Разграничение прав доступа для администраторов, преподавателей и слушателей
- Динамическая проверка разрешений на уровне компонентов

### Административная панель
- Управление пользователями, программами обучения и словарями
- Система рекомендаций для подбора программ
- Интерактивные таблицы с фильтрацией, сортировкой и поиском (Ant Design Table)
- Модальные окна для быстрого редактирования данных

### PDF-генератор
- Создание документов по госстандартам РФ
- Поддержка кастомных шрифтов (в т.ч. кириллицы)
- Многостраничная структура с автоматическим разбиением контента
- Генерация удостоверений, сертификатов и отчётов

## Мои достижения

- Разработал систему генерации официальных документов, соответствующих госстандартам
- Внедрил ролевую модель доступа с гибкой системой разрешений
- Реализовал административную панель с полным функционалом управления
- Настроил оптимистичные обновления для улучшения UX
- Создал переиспользуемые UI-компоненты на базе Ant Design

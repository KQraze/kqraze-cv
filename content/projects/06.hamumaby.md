# Hamumaby - интернет-магазин

Разработка интернет-магазина детских товаров с современным интерфейсом, каталогом продукции и функциональной системой фильтрации.

## О проекте

Быстрая разработка интернет-магазина за 1 месяц с полной реализацией дизайна из Figma. Проект требовал точности в вёрстке и эффективной организации кода.

## Вёрстка по дизайну

### Работа с Figma
- Pixel-perfect реализация макетов
- Корректное воспроизведение типографики и spacing
- Адаптация дизайна под разные разрешения
- Согласование спорных моментов с дизайнером

### Tailwind CSS подход
- Использование utility-классов для быстрой разработки
- Кастомизация темы под требования дизайна
- Создание переиспользуемых компонентов
- Responsive design с помощью breakpoints

## Методологии и организация кода

### БЭМ (Block Element Modifier)
- Именование классов по методологии БЭМ
- Изолированные стили для компонентов
- Модификаторы для вариативности компонентов
- Избежание конфликтов стилей

### Feature-Sliced Design
- Организация структуры проекта по FSD
- Разделение на entities (товары, категории)
- Features для бизнес-логики (фильтрация, корзина)
- Shared слой с UI-компонентами

## Функциональность

### Каталог товаров
- Отображение карточек товаров с изображениями
- Пагинация для больших списков
- Сортировка по различным параметрам
- Детальная страница товара

### Система фильтрации
- Многокритериальная фильтрация (цена, категория, бренд)
- Динамическое обновление результатов
- Сохранение состояния фильтров
- Счётчики количества товаров по фильтрам

### Работа с данными
- Интеграция с REST API для каталога
- Управление состоянием через Pinia stores
- Оптимизация запросов к серверу
- Кэширование данных для производительности

## Адаптивность

### Мобильная версия
- Адаптация под экраны смартфонов (320px+)
- Touch-friendly интерфейс
- Оптимизация изображений для мобильных
- Мобильное меню и навигация

### Кроссбраузерность
- Тестирование в Chrome, Firefox, Safari, Edge
- Полифиллы для старых браузеров
- Fallback для CSS Grid и Flexbox
- Проверка на совместимость

- Обеспечил отличную производительность и UX

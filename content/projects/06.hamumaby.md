# Hamumaby - интернет-магазин

Разработка интернет-магазина с современным интерфейсом и функциональной системой фильтрации товаров.

## Особенности реализации

- Точная вёрстка по макетам Figma
- Использование Tailwind CSS для быстрой стилизации
- Организация кода по методологиям BEM и FSD
- Адаптивная и кроссбраузерная вёрстка

## Функциональность

- Интеграция с REST API для работы с данными
- Система фильтрации товаров
- Управление состоянием через Pinia
- Оптимизированная производительность

# ProfTeam - платформа для студентов и работодателей

Первый коммерческий проект - платформа для связи студентов и работодателей. Опыт работы в Scrum-команде.

## Начало карьеры

Этот проект стал отправной точкой в профессиональной разработке, где я получил опыт работы в команде по Agile-методологии.

## Реализованные задачи

- Разработка SPA на Vue.js
- Работа с REST API
- Участие в командной разработке по Scrum
- Использование GitHub Projects для управления задачами
- Оптимизация процесса взаимодействия между студентами и работодателями

## Командная работа

Опыт работы в Scrum-команде с регулярными встречами, ретроспективами и использованием инструментов для отслеживания прогресса.

# ProfTeam - платформа для студентов и работодателей

Первый коммерческий проект - платформа для оптимизации взаимодействия между студентами и работодателями. Здесь я получил первый опыт профессиональной разработки в Scrum-команде.

## О проекте

ProfTeam - это платформа, упрощающая процесс поиска стажировок и работы для студентов, а также подбор молодых специалистов для компаний. Проект включает личные кабинеты студентов и работодателей, систему откликов и управление вакансиями.

## Начало профессионального пути

Этот проект стал важной вехой в моей карьере - первый опыт работы в команде разработчиков, первое знакомство с реальными задачами и процессами коммерческой разработки.

## Технические задачи

### Разработка SPA

**Vue.js приложение**
- Работа с Vue 2 Options API
- Создание компонентов для различных разделов
- Управление состоянием приложения
- Роутинг между страницами

**Функциональность**
- Профили студентов и работодателей
- Каталог вакансий с фильтрацией
- Система откликов на вакансии
- Личные кабинеты пользователей

### Интеграция с API

**REST API**
- Изучение документации API
- Реализация HTTP-запросов
- Обработка ответов и ошибок
- Работа с авторизацией

**Работа с данными**
- Получение списков вакансий
- Загрузка профилей пользователей
- Отправка откликов
- Обновление данных профиля

## Scrum-методология

### Agile-процесс

**Sprint Planning**
- Участие в планировании спринта
- Оценка задач в story points
- Декомпозиция крупных задач
- Выбор задач в работу

**Daily Stand-up**
- Ежедневные синхронизации команды
- Отчёт о прогрессе и блокерах
- Координация с коллегами
- Планирование дня

**Sprint Retrospective**
- Обсуждение результатов спринта
- Анализ проблем и успехов
- Предложения по улучшению процессов
- Командный рост

### Инструменты

**GitHub Projects**
- Kanban-доска для отслеживания задач
- Управление беклогом
- Статусы задач (To Do, In Progress, Done)
- Связь задач с Pull Request

**Git & GitHub**
- Работа с ветками (feature branches)
- Создание Pull Request
- Разрешение конфликтов
- Commit conventions

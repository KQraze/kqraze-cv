# Парта героя

Проект социального значения, объединяющий дизайн и разработку. Полный цикл от проектирования интерфейса до реализации функционального веб-приложения.

## Роль в проекте

Совмещение ролей UX/UI дизайнера и Frontend-разработчика позволило создать целостный продукт с продуманным пользовательским опытом.

## Реализованный функционал

- Проектирование интерфейса в Figma с учётом лучших практик UX/UI
- Разработка с нуля на Vue.js с использованием TypeScript для типобезопасности
- Система фильтрации данных для удобного поиска
- Интеграция с REST API
- Адаптивный дизайн для всех типов устройств

## Технологии

Использован современный стек Vue.js экосистемы с управлением состоянием через Pinia.

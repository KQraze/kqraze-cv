# Парта героя

Социальный проект, посвящённый памяти героев. Выполнил полный цикл работ от проектирования интерфейса в Figma до реализации функционального веб-приложения.

## О проекте

Платформа для увековечивания памяти героев с интерактивной системой поиска и фильтрации. Проект имеет большое социальное значение, объединяя людей через истории героизма.

## Двойная роль в проекте

### UX/UI Дизайнер
Проектирование интерфейса с нуля в Figma:
- Исследование целевой аудитории и пользовательских сценариев
- Создание wireframes и прототипов
- Разработка дизайн-системы с унифицированными компонентами
- Проектирование адаптивных макетов для разных устройств
- Учёт accessibility и доступности интерфейса

### Frontend-разработчик
Полная реализация спроектированного интерфейса:
- Трансформация дизайна в код с pixel-perfect точностью
- Реализация интерактивных элементов и анимаций
- Обеспечение кроссбраузерной совместимости

## Реализованный функционал

**Система фильтрации**
- Многокритериальный поиск по базе данных
- Динамическая фильтрация без перезагрузки страницы
- Сохранение состояния фильтров
- Оптимизация запросов к API

**Работа с данными**
- Интеграция с REST API для получения информации о героях
- Реактивное управление состоянием через Pinia
- Кэширование данных для быстрого доступа
- Обработка ошибок и состояний загрузки

**Адаптивность**
- Полная адаптация под мобильные устройства
- Отзывчивый дизайн для планшетов
- Оптимизация для touch-взаимодействий
- Progressive Enhancement подход

## Достижения

- Спроектировал и реализовал полноценное веб-приложение за 2 месяца
- Совместил роли дизайнера и разработчика для создания целостного продукта
- Создал интуитивный интерфейс для пользователей разных возрастов
- Реализовал эффективную систему поиска и фильтрации

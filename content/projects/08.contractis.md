# Contractis - платформа управления контрактами

Полнофункциональная платформа для управления контрактами с серверным рендерингом и системой реального времени.

## Масштаб проекта

Разработка клиентской части с нуля с использованием полного стека современных технологий Vue/Nuxt экосистемы.

## Технические особенности

- Серверный рендеринг (SSR) для оптимальной SEO-оптимизации
- Интеграция с WebSocket через Centrifugo для обновлений в реальном времени
- Ролевая система доступа на клиентской стороне
- Разработка UI-компонентов по макетам Figma
- Код-ревью в команде

## Использованный стек

Современный стек на базе Nuxt 3 с Composition API, полной типизацией TypeScript и стилизацией через Tailwind CSS и SCSS с методологией БЭМ.

# Contractis - платформа управления контрактами

Enterprise-платформа для управления деловыми контрактами с полным циклом от создания до исполнения. Разработка клиентской части с нуля на Nuxt 3.

## О проекте

Масштабная система для автоматизации работы с контрактами: создание, согласование, подписание и контроль исполнения. Платформа включает сложную ролевую модель, уведомления в реальном времени и интеграцию с внешними сервисами.

## Разработка с нуля

### Архитектура приложения

**Nuxt 3 + SSR**
- Серверный рендеринг для быстрой загрузки и SEO
- Universal rendering для оптимального UX
- Гидратация на клиенте без потери состояния
- Оптимизация метатегов и Open Graph

**Современный стек**
- Vue 3 Composition API для реактивности
- TypeScript для типобезопасности
- Pinia для управления состоянием
- Tailwind CSS + SCSS для стилизации

### Работа с дизайном

**Реализация макетов Figma**
- Разработка UI-компонентов по готовым макетам
- Pixel-perfect вёрстка интерфейсов
- Адаптация под различные разрешения
- Создание UI-кита переиспользуемых компонентов

**Методология БЭМ**
- Структурированное именование классов
- Изолированные стили компонентов
- Модификаторы для вариаций
- Предсказуемость и читаемость кода

## Ключевые функции

### Ролевая система

**Разграничение доступа**
- Роли: администратор, менеджер, исполнитель, клиент
- Гибкая система разрешений (permissions)
- Условный рендеринг UI в зависимости от роли
- Защита роутов на основе прав доступа

**Реализация на клиенте**
- Middleware для проверки прав
- Композаблы для работы с ролями
- Динамическое меню и навигация
- Контроль доступа к функциям

### Интеграция с REST API

**Работа с Postman документацией**
- Изучение API спецификации
- Типизация запросов и ответов
- Создание API-слоя с axios
- Обработка ошибок и retry-логика

**Управление данными**
- CRUD операции для контрактов
- Загрузка и управление документами
- Фильтрация и поиск
- Пагинация больших списков

### Centrifugo WebSocket

**Реальное время**
- Подключение к Centrifugo серверу
- Подписка на каналы событий
- Обработка уведомлений о изменениях
- Автоматическое обновление данных

**Типы событий**
- Изменение статуса контракта
- Новые комментарии и согласования
- Уведомления о дедлайнах
- Системные сообщения

## Услуги

### Разработка веб-приложений
Мы разрабатываем полнофункциональные веб-приложения на Vue 3 и Nuxt 3 с использованием TypeScript.

### Дизайн интерфейсов
Создаём красивые и интуитивные интерфейсы с использованием Tailwind CSS и современных подходов UX/UI.

### Консультации
Помогаем выбрать правильные технологии и архитектуру для вашего проекта.

## Технологический стек

- **Фреймворк**: Nuxt 3
- **Язык**: TypeScript
- **Стилизация**: Tailwind CSS
- **Контент**: @nuxt/content
- **ОС**: Linux
